# Section 3: Control Problems using Python

## Duration
- Practice: 1 hour
- Quiz: 30 minutes

## Learning Objectives
Students will be able to:
- Create transfer functions using Python.
- Find poles of a system.
- Plot step response.
- Check system stability.

## Practice Task

Given:

G(s) = 10 / (s² + 5s + 6)

Students must:
1. Create transfer function.
2. Find poles.
3. Plot step response.
4. Check stability.

## Expected Poles

s = -2, -3

Since both poles are negative, the system is stable.
