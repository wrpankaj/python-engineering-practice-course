# Section 4: Spreadsheet Processing using Python

## Duration
- Practice: 1 hour
- Quiz: 30 minutes

## Learning Objectives
Students will be able to:
- Create Excel files using pandas.
- Read spreadsheet data.
- Compute average quiz marks.
- Export processed data to Excel.

## Practice Task

Create a spreadsheet with:

| Student_ID | Quiz1 | Quiz2 | Quiz3 |
|---|---:|---:|---:|
| 101 | 20 | 25 | 30 |
| 102 | 18 | 22 | 24 |
| 103 | 25 | 25 | 25 |

Students must:
1. Create Excel file.
2. Read Excel file.
3. Add Average column.
4. Export updated Excel file.

## Expected Average for Student 101

Average = 25
