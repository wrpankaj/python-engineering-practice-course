# Section 2: Efficiency Problems using Python

## Duration
- Practice: 1 hour
- Quiz: 30 minutes

## Learning Objectives
Students will be able to:
- Understand efficiency formulas.
- Write reusable Python functions/classes.
- Calculate mechanical, boiler and pump efficiency.

## Practice Tasks

### Task 1: Mechanical Efficiency

Input Power = 1000 W  
Output Power = 750 W  

Find mechanical efficiency.

### Task 2: Boiler Efficiency

Heat Input = 12000 kJ  
Useful Heat Output = 9000 kJ  

Find boiler efficiency.

### Task 3: Pump Efficiency

rho = 1000 kg/m³  
g = 9.81 m/s²  
Q = 0.02 m³/s  
H = 20 m  
Input Power = 5000 W

Find pump efficiency.
