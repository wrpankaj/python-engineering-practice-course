# Quiz Bank: Python Engineering Practice Course

Each section quiz may be conducted for **10 marks** in **30 minutes**.

## Section 1 Quiz: Optimization

1. Which SciPy function is used for Linear Programming?  
   A. minimize() B. linprog() C. polyfit() D. odeint()  
   **Answer: B**

2. For maximizing profit using linprog(), objective coefficients are entered as negative values.  
   **Answer: True**

3. Maximize Z = 3x + 5y at x = 2, y = 2. Find Z.  
   **Answer: 16**

4. Match:  
   Objective function → Function to maximize/minimize  
   Constraint → Restriction  
   Decision variable → Unknown variable  
   Feasible region → Valid solution area

## Section 2 Quiz: Efficiency

1. Efficiency formula is Output/Input × 100.  
   **Answer: True**

2. Input = 1000 W, Output = 750 W. Efficiency = ?  
   **Answer: 75%**

3. Boiler heat input = 12000 kJ, heat output = 9000 kJ. Efficiency = ?  
   **Answer: 75%**

4. Pump hydraulic power formula is rho*g*Q*H.  
   **Answer: True**

## Section 3 Quiz: Control Systems

1. Which library is used for control systems in Python?  
   **Answer: control**

2. Poles of s² + 5s + 6 are:  
   **Answer: -2, -3**

3. Stable system has poles with negative real parts.  
   **Answer: True**

4. Transfer function is ratio of output to input in Laplace domain.  
   **Answer: True**
