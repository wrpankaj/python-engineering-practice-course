# Python Engineering Practice Course

## Course Title
**Python for Engineering Applications: Optimization, Efficiency, Control Systems and Spreadsheet Automation**

## Course Duration
Each section contains:
- **1 hour practice**
- **30 minutes quiz**

Total duration:
- 4 sections × 1.5 hours = **6 hours**

## Total Assessment
- Each section quiz: 10 marks
- Suggested final evaluation: Average of all four quizzes or total out of 40

## Course Sections

| Section | Topic | Practice Duration | Quiz Duration |
|---|---|---:|---:|
| 1 | Optimization Problems using SciPy | 1 hour | 30 minutes |
| 2 | Efficiency Problems using Python | 1 hour | 30 minutes |
| 3 | Control Problems using Python | 1 hour | 30 minutes |
| 4 | Spreadsheet Processing using Python | 1 hour | 30 minutes |

## Required Python Libraries

```bash
pip install numpy scipy pandas matplotlib control openpyxl
```

## How Students Should Use This Course

1. Open each topic folder.
2. Read the `README.md`.
3. Run the Python practice file.
4. Complete the quiz after practice.
5. Submit screenshots, code files and output files.

## Course Outcomes

After completing this course, students will be able to:

- Formulate and solve optimization problems using SciPy.
- Calculate engineering efficiencies using Python.
- Analyze transfer functions and control system responses.
- Process Excel data using pandas.
- Use Python libraries for engineering problem solving.
