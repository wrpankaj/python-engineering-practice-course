# Section 1: Optimization Problems using SciPy

## Duration
- Practice: 1 hour
- Quiz: 30 minutes

## Learning Objectives
Students will be able to:
- Understand objective functions, constraints and decision variables.
- Formulate Linear Programming Problems.
- Solve constrained and unconstrained optimization problems using SciPy.

## Practice Tasks

### Task 1: Linear Programming Problem

A furniture manufacturing company makes chairs and tables.

Maximize:

Z = 45x1 + 80x2

Subject to:

5x1 + 20x2 <= 400  
10x1 + 15x2 <= 450  
x1, x2 >= 0

Find:
- Number of chairs
- Number of tables
- Maximum profit

### Task 2: Unconstrained Optimization

Minimize:

f(x) = x² + 3x + 2

## Expected Output

For Task 1:

Chairs = 24  
Tables = 14  
Maximum Profit = Rs. 2200
